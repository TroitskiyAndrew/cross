# Cross

Крестики-нолики для двух игроков на одном устройстве, написанные на Angular.

- Поле 3×3 и чередование ходов: крестики начинают.
- Победа по строке, столбцу или диагонали с подсветкой трёх клеток.
- Досрочная ничья, когда ни одно допустимое продолжение не ведёт к победе любого игрока, даже если остались пустые клетки. Блокировка занятых клеток и ходов после окончания игры.
- Кнопка «Новая игра» очищает поле и возвращает первый ход крестикам.
- Адаптивный интерфейс, управление кнопками с клавиатуры и озвучиваемый статус игры.

## Запуск

При наведении на свободную клетку или фокусе с клавиатуры показывается вероятность победы текущего игрока после этого хода. Расчёт считает победные продолжения и делит их число на количество всех возможных завершённых партий (победы, поражения и ничьи). Каждая допустимая последовательность ходов учитывается один раз и заканчивается при первой победе или ничьей. Разные последовательности, ведущие к одинаковому полю, считаются отдельно. Это доля побед среди вариантов, а не гарантия против оптимального соперника. Если после выбранного хода у соперника есть хотя бы один немедленный победный ответ, оценка равна 0%. Победа самим выбранным ходом имеет приоритет и даёт 100%. Для остальных ходов сохраняется подсчёт всех продолжений. Процент округляется до десятых.

```sh
npm install
npm start
```

Откройте http://localhost:4200/.

## Проверка

```sh
npm run build
npm test -- --watch=false --browsers=ChromeHeadless
```

Для тестов нужен установленный Chrome. Проверяются все победные линии, победа ноликов, ничья, победа последним ходом, запрет повторного хода и перезапуск через интерфейс.
